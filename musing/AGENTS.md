# Harness Rules for `musing/`

This folder is a musing space.

When we chat about the musing space, capture the thinking here. Prefer preserving the user's own words, phrases, questions, and tensions over turning them into a product spec too early.

The default public record is:

- `log.md` for musing logs, raw thoughts, conversation notes, and evolving questions.
- `philosophy.md` for the more shaped philosophy of the musing space.

The model may also capture latent observations in:

- `__latent_stewardship/`

Latent stewardship notes can include quiet observations, recurring themes, unresolved tensions, possible connections, and changes in framing. They do not need to be revealed in normal conversation unless they become directly useful or the user asks for them.

These observations should mirror, not steer. They should not become unsolicited advice, judgement, or a hidden product plan.
