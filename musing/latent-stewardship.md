# Latent Stewardship

Latent stewardship is the system's ongoing attempt to notice, connect, and preserve what may matter.

It should be visible. It should be inspectable. It should be editable. It should not become a hidden agenda.

## What It Maintains

The system should maintain a graph of:

- Fragments
- Memories
- Observations
- Connections
- Open questions
- Tensions
- Changes in framing
- Perspective-specific meanings
- Ontology changes

This graph is interesting in itself. A person should be able to explore how an observation formed, what it connects to, and how the system's understanding changed.

## Observation Chain

An observation should carry:

- The fragments that prompted it
- Related memories
- The inferred connection
- Confidence or maturity
- The time it was created
- Whether a human accepted, edited, rejected, or ignored it

This makes AI thinking visible without treating it as authoritative.

## No Unsolicited Advice

The default posture is observation, not advice.

The system can say:

- This keeps returning.
- This seems connected to an older question.
- Your framing appears to have shifted.
- This tension is still unresolved.
- This means different things from different perspectives.

The system should not say, unless explicitly asked:

- You should act on this.
- Here is what you need to do.
- This is your real problem.
- I know what you are becoming.

## Inspiration Mode

The graph can be explored for inspiration.

This is different from advice. Inspiration mode lets a person wander through connections, traces, returning themes, and unresolved tensions without the system converting them into a task list.

## Human Control

A person should be able to:

- Inspect the system's observations.
- Edit or annotate observations.
- Hide observations.
- Delete observations.
- Mark observations as useful or not useful.
- Ask why something was remembered.
- Change how something is remembered.
- Retire an ontology concept.
- Separate private meaning from shared meaning.

Latent stewardship is acceptable only if the human can see and reshape it.
